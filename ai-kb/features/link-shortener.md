# Link Shortener

## Overview
LinkForge's Link Shortener transforms long URLs into short, branded links that are easy to share and track.

## Key Features

### 1. Create Short Links
- Paste any long URL and get a short link instantly
- Short links use the format: `yourdomain.com/abc123`
- Each short code is 7 characters by default

### 2. Custom Aliases
- Instead of random characters, use memorable names
- Example: `linkforge.io/summer-sale` instead of `linkforge.io/x7Kp2mN`
- Aliases must be unique within your workspace

### 3. Password Protection
- Add a password to restrict access to your links
- Users must enter the password before being redirected
- Maximum 5 failed attempts, then 15-minute lockout

### 4. Link Expiration
- Set a start date: link only works after this date
- Set an expiry date: link stops working after this date
- Perfect for time-sensitive campaigns

### 5. UTM Parameters
- Add tracking parameters automatically:
  - Source: Where traffic comes from (facebook, google)
  - Medium: Marketing medium (cpc, email, social)
  - Campaign: Campaign name (summer-sale)
  - Term: Paid keywords
  - Content: A/B test variants

### 6. Mobile Deep Linking
- iOS: Custom URL schemes and App Store fallback
- Android: Custom URL schemes and Play Store fallback
- Automatically detects device and redirects appropriately

## How to Create a Link

1. Go to **Dashboard → Links**
2. Click **"Create Link"** button
3. Enter the destination URL
4. (Optional) Add a custom alias
5. (Optional) Configure advanced options:
   - Password protection
   - Expiration dates
   - UTM parameters
   - Mobile deep links
6. Click **"Create"**
7. Copy your new short link

## How to Edit a Link

1. Go to **Dashboard → Links**
2. Find your link in the list
3. Click the **edit icon** or link title
4. Modify any settings
5. Click **"Save Changes"**

## How to Delete a Link

1. Go to **Dashboard → Links**
2. Find your link in the list
3. Click the **delete icon**
4. Confirm deletion

**Note:** Deleted links cannot be recovered. The short code becomes available for reuse.

## Link Analytics

Each link tracks:
- Total clicks
- Unique visitors
- Geographic location
- Device type (mobile/desktop/tablet)
- Browser and OS
- Referrer source
- Click timestamps

## Best Practices

1. **Use descriptive aliases** - Makes links memorable and trustworthy
2. **Add UTM parameters** - Track marketing campaign performance
3. **Set expiration dates** for promotions - Prevents outdated links from being used
4. **Use folders and tags** - Organize links for easy management
