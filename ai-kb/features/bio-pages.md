# Bio Pages

## Overview
Create beautiful landing pages with all your important links in one place. Perfect for Instagram bio, TikTok, Twitter, or anywhere you can only share one link.

## What is a Bio Page?

A Bio Page is a customizable landing page that contains:
- Your profile/brand info
- Multiple links to your content
- Social media icons
- Custom styling and branding

Example URL: `linkforge.io/bio/yourname`

## Block Types

### 1. Header Block
- Add a title or your name
- Optional subtitle
- Profile picture/logo

### 2. Link Block
- Clickable button that links to any URL
- Customize button text
- Optional icon
- Track clicks

### 3. Social Block
- Icons for social media platforms
- Supported: Instagram, Twitter/X, Facebook, LinkedIn, TikTok, YouTube, GitHub, Pinterest, Snapchat
- Opens profile in new tab

### 4. Text Block
- Add any text content
- Support for descriptions, announcements, bios
- Markdown formatting available

### 5. Divider Block
- Visual separator between sections
- Line style options
- Adds visual structure

### 6. Image Block
- Add images to your page
- Upload or use URL
- Click to enlarge option

### 7. Contact Block
- Display contact information
- Email, phone number
- Location/address
- Click to call/email

## How to Create a Bio Page

1. Go to **Dashboard → Bio Pages**
2. Click **"Create New Page"**
3. Choose your page slug (URL path)
4. Select a theme
5. Add blocks:
   - Click **"Add Block"**
   - Choose block type
   - Fill in content
   - Drag to reorder
6. Click **"Preview"** to see your page
7. Click **"Publish"** when ready

## Customization Options

### Page Settings
- **Title** - Page name for your reference
- **Slug** - URL path (e.g., /bio/yourname)
- **Theme** - Visual style
- **Background Color** - Custom background
- **Background Image** - Upload custom background

### Meta Information
- **Meta Title** - Browser tab title
- **Meta Description** - For SEO and sharing
- **OG Image** - Image shown when shared on social

### Custom CSS
For advanced users, add custom CSS to fully customize your page appearance.

## Managing Blocks

### Add Blocks
1. Click **"Add Block"** button
2. Select block type
3. Fill in details
4. Block appears at bottom

### Reorder Blocks
- Drag and drop blocks to change order
- Use up/down arrows
- Changes save automatically

### Edit Blocks
1. Click on any block
2. Edit content in the sidebar
3. See changes in real-time preview

### Delete Blocks
1. Click on the block
2. Click **"Delete"** button
3. Confirm deletion

## Publishing

### Draft Mode
- Page is not publicly visible
- Only you can preview it
- Make changes freely

### Published
- Page is live and accessible
- Anyone with the URL can view
- Changes go live immediately

## Best Practices

1. **Keep it simple** - Don't add too many links (5-7 is ideal)
2. **Prioritize** - Put most important links at top
3. **Use clear text** - Make button labels descriptive
4. **Add personality** - Use your brand colors and style
5. **Update regularly** - Keep links fresh and relevant
6. **Test on mobile** - Most visitors use phones
