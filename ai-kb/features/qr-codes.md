# QR Code Generator

## Overview
Create beautiful, customizable QR codes for any purpose. QR codes can be scanned with any smartphone camera.

## QR Code Types

### 1. URL QR Code
Opens a website when scanned.
- Enter any website URL
- Can be linked to a short link for tracking

### 2. Contact Card (vCard)
Saves contact information to the phone.
- First name, Last name
- Phone number
- Email address
- Company, Job title
- Website
- Address

### 3. WiFi QR Code
Connects to WiFi network automatically.
- Network name (SSID)
- Password
- Security type (WPA/WPA2, WEP, None)
- Hidden network option

### 4. SMS QR Code
Opens a pre-filled text message.
- Phone number
- Pre-written message

### 5. Email QR Code
Opens email app with pre-filled content.
- Recipient email
- Subject line
- Message body

### 6. Plain Text QR Code
Displays any text message.
- Any text up to 4,296 characters

## Customization Options

### Colors
- **Foreground color**: The color of the QR code dots (default: black)
- **Background color**: The background behind the QR code (default: white)
- Use contrasting colors for best scanning

### Dot Styles
- Square (default)
- Rounded
- Dots
- Extra rounded

### Corner Styles
- Square (default)
- Rounded
- Extra rounded

### Logo
- Add your logo to the center of the QR code
- Adjust logo size (10-40% of QR code)
- Add padding around the logo
- Supported formats: PNG, JPG, SVG

### Frames
- Add a frame around your QR code
- Include call-to-action text like "Scan Me!"
- Frame color customization

## How to Create a QR Code

1. Go to **Dashboard → QR Code**
2. Select the QR code type (URL, Contact, WiFi, etc.)
3. Fill in the required information
4. Customize appearance:
   - Choose colors
   - Select dot and corner styles
   - Upload logo (optional)
   - Add frame (optional)
5. Preview your QR code in real-time
6. Click **"Download PNG"** or **"Download SVG"**

## Download Formats

### PNG (Recommended for most uses)
- Raster image format
- Best for printing, social media, websites
- Choose size: 300px, 500px, 1000px, 2000px

### SVG (For professionals)
- Vector format
- Infinitely scalable without quality loss
- Best for large prints, billboards, professional design

## QR Code Templates

Save your favorite QR code designs as templates:
1. Create a QR code with your preferred styling
2. Click **"Save as Template"**
3. Name your template
4. Reuse for future QR codes

## Best Practices

1. **Test before printing** - Always scan your QR code to verify it works
2. **Minimum size** - Print at least 2cm x 2cm (0.8in x 0.8in)
3. **Quiet zone** - Keep white space around the QR code
4. **Contrast** - Use dark foreground on light background
5. **Logo size** - Keep logo under 30% of QR code area
6. **Error correction** - Higher error correction allows more customization
